# Adding the Attached Images

## Add the three attached images for the task

To add the task table images:

1. Copy the three table images into this folder:
   - `C:\python\python-course-assignments\python-course-assignments\Project mouse monitor OCR\sample_test\pic day 3\`

2. File names should use a digital timestamp format:
   - Example: `20260713_100000.jpg` or `20260713_100001.jpg`

3. After adding the images, the project will be ready to use.
