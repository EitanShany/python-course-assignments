# Sample Test Data

This folder contains sample test data for the Mouse Monitor OCR project.

## Add Additional Images

To add more table images for the task:

1. Place the image files (JPG, PNG) in the appropriate folders:
   - `pic day 1/` - images from day 1
   - `pic day 2/` - images from day 2
   - create a new folder for additional days

2. File names should use this format:
   - `YYYYMMDD_HHMMSS.jpg` or `YYYYMMDD_HHMMSS.png`
   - Example: `20260713_103000.jpg`
